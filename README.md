# Paris — Mon Parcours

A lightweight web app designed to help travelers discover Paris from their phones. It offers 1 to 5-day itineraries, complete with a map and progress tracking.

## Features

* **Interactive map**: Visualization of the complete route and the different stops (using Leaflet.js).
* **Multilingual**: Interface and content in French, English, and Korean, with instant language switching.
* **Adjustable itineraries**: Routes generated based on the chosen length of stay.
* **Visit tracking**: Checklist system with a progress bar.
* **Mobile interface**: Navigation and typography specifically designed for smartphone use.
* **Minimalist analytics**: Built-in visit tracking via GoatCounter (cookie-free, requires no GDPR banner).

## Technologies used

* HTML / CSS / Vanilla JavaScript (no framework)
* Leaflet.js & OpenStreetMap
* Fonts: Inter & Syne (Google Fonts)
